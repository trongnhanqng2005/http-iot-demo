# UI/UX Pro Max Rules

This project follows the UI/UX Pro Max skill guidelines for Developer Tools and Dashboards.
Styles: Minimalism & Swiss Style, Data-Dense Developer Dashboard.
Colors: Slate neutral palette with Emerald (Success), Cyan (Actions/Protocol), Amber (Warning), Rose (Error).
Fonts: Plus Jakarta Sans for UI, JetBrains Mono for code and data.
Accessibility: WCAG AA contrast >= 4.5:1, keyboard navigability, clear focus rings.
Icons: Lucide React only.
